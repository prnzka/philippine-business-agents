# Primary Sources

Agents must verify volatile figures here, not against blogs or SEO guides. Most
third-party "2026 contribution table" pages are wrong, stale, or copied from each other.

## Tax

| What | Where |
|---|---|
| Revenue Regulations, RMCs, rulings | bir.gov.ph → Issuances |
| Tax forms (1701A, 1701Q, 2550Q, 1601-C, 2307, 0619-E) | bir.gov.ph → Forms |
| eFPS / eBIRForms | efps.bir.gov.ph, bir.gov.ph |
| ORUS (Online Registration & Update System) | orus.bir.gov.ph |
| Tax Code as amended (TRAIN RA 10963, CREATE RA 11534, EOPT RA 11976, CREATE MORE RA 12066, VAT on digital services RA 12023) | lawphil.net, officialgazette.gov.ph |

## Labour & social contributions

| What | Where |
|---|---|
| Regional minimum wage, current wage orders | nwpc.dole.gov.ph |
| Labour advisories, DOLE orders, 13th month rules | dole.gov.ph |
| SSS contribution schedule | sss.gov.ph → Circulars |
| PhilHealth premium circulars | philhealth.gov.ph → Circulars |
| Pag-IBIG contribution rules | pagibigfund.gov.ph |

> **Wage orders are litigated.** NCR orders have been enjoined by courts mid-effectivity.
> Never quote a rate without checking whether the order is in force.
